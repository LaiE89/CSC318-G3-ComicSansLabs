# CSC318-G3-ComicSansLabs

## Summary
Contains a high-fidelity prototype implementation of the app iGather.

## Running the app
1. `git clone https://github.com/LaiE89/CSC318-G3-ComicSansLabs.git`
2. `cd CSC318-G3-ComicSansLabs/igather`
3. `npm install`
4. `npm run dev`
5. Open `http://localhost:3000` with your browser to use the prototype
